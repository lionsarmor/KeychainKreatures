# Delivery, inspection and first tests

Before shipment, request the agreed bare-board electrical-test results and power assembly inspection/hidden-joint reports. Save them under Inspection_Reports. Shipping dates and tracking are not yet known.

On arrival: photograph and label all five samples of each board; inspect without power; compare outlines, mounting holes and connectors to the current drawings. Use the included main/power troubleshooting PDFs and blank records. PCBWay assembly does not mean the circuit has already passed our functional tests.

Test power independently before connecting the populated main board. Follow P4_REVIEW_AND_TEST.md and the instructor-level power guide. Do not connect an unspecified battery. BAT_NEG is not system GND; do not bypass protection with grounded equipment. Charging tests need suitable sink-capable equipment or a qualified cell/NTC, not an ordinary bench supply used as a battery.

No diagnostic/production firmware is supplied or claimed implemented. If PCBWay asks for firmware or a functional fixture, agree that separate scope first; do not upload historical incompatible code.

KIT_EXTRAS_FOR_LOCAL_BUILD.csv is reference for assembling complete pairs locally, NOT an additional power-board sourcing BOM. Count extras once per main+power pair; unresolved battery/mechanical selections remain open. Use FACTORY_FAULT_REPORT.pdf for issues.
