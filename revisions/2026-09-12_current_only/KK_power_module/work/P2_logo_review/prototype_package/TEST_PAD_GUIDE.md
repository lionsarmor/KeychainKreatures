# Test-pad guide — rear side

28 bare 1.5 mm probe pads; not fitted pins. Coordinates are front-view KiCad mm (Y down). The rear assembly drawing is mirrored for rear viewing.

**TP4 is GND. TP3 is BAT_NEG, not an interchangeable ground. Never bridge the protection return with grounded test equipment.**
